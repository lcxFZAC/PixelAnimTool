# PixelAnimTool · 像素工坊

Windows 本地内容工坊与 Gemini Gem 在线方案，分别放在两个目录中。界面和说明使用中文。

## 从哪里开始

- **在自己电脑上修图、预览、导出**：双击 [`local-workshop/Start-Workshop.cmd`](local-workshop/Start-Workshop.cmd)，首次准备独立运行环境，之后自动打开浏览器。先读 [本地工坊新手指南](local-workshop/README.md)。需要已安装 Python 3.10+；本机已准备好独立环境。
- **在 Gemini 官网“一张图＋关键词”制作候选**：按 [Gem 安装指南](gem-online/README.md) 新建自己的 Gem，复制指令、上传标准文件。Gem 使用不需要本地工坊运行。
- **全在线处理、修图与 ZIP 导出**：`gem-online` 还提供 Docker 和 Render 部署配置。部署后直接用网页工作；不需要使用者启动本地服务。部署由你自己的云账号承载，见在线指南。

## 已实现

本地网页由 Python 后台托管；WebGL 使用最近邻实时预览，图层编辑在原生像素网格进行。无需 Unity、Node、前端构建或 CDN。

- 角色参考图、三种风格配方、像素画布与 PPU 下拉选项。
- 原生图集导入、等分切帧、边缘连通去背、整段统一缩放、共享色板、固定描边。
- 像素铅笔、橡皮、填充、吸色、直线、矩形、椭圆、选区、移动、选区复制粘贴。
- 每帧多图层、显示隐藏、重排、重命名；逐帧时间轴、复制/添加/删除/调序、洋葱皮、循环与 FPS。
- 撤销重做、自动保存、项目重开、图集哈希验收、PNG/JSON/APNG/可编辑项目 ZIP 导出。
- 默认关闭的 Gemini API 接口；开启后可用个人 Key，动作包任务队列、进度、取消后续请求、缺失动作续做、单动作替换、方向母版引用与源稿保存。
- Gem 指令包、知识标准、在线工坊部署配置，以及个人访问口令保护。

## 质量与交付状态

这是一套可运行的制作工具，不承诺任意立绘一次生成完美动画。确定性处理和检查只能保证所检查的工程属性，不能自动证明手形、身份、配饰与动作自然。所有 AI 图集默认待视觉验收，编辑后自动重置认可状态。

“玖镇”借鉴 NovemHD2D 的清晰像素、固定描边、低位步态和人工验收原则。本次没有更改 NovemHD2D 的角色生产入口，也没有把练习素材标成游戏正式角色。

**Gem 是可复制安装的在线对话配置包，不是 Gemini 官方提供的自定义可执行插件。** 官方 Gem 指令/知识机制不能等价为自定义后台调用能力。Gem 图稿传入工坊目前是手动上传；完整自动生产使用工坊内的 Gemini API 入口。两种入口的区别在指南中明确列出。

实际验证记录见 [本地验证说明](local-workshop/VERIFICATION.md)。未配置有效 Key，真实云端生图质量、付费调用、Gem 账号内安装与云端部署不在已验证范围；没有伪造在线地址或生图成功率。

## 目录

```text
PixelAnimTool/
  local-workshop/       Windows 工坊、像素编辑器、生成与导出引擎
    Start-Workshop.cmd 一键入口
    static/            页面与 WebGL 编辑器
    data/              自动生成的私有项目文件（不进 Git）
    examples/          编辑练习图，不是角色成品
    tests/             不调用真实 Gemini 的回归检查
  gem-online/          Gem 指令/知识包、在线部署配置
```

不要把 API Key 写进仓库或发到聊天中。只在工坊的密码框输入；Key 不进入项目或导出包，刷新页面后需要重新输入。
