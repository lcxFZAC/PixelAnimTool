# 本地像素工坊 · 新手指南

## 1. 第一次启动

1. Windows 10/11 上准备 Python 3.10 或更新版本。没有 Python 时，从 [Python 官方 Windows 下载页](https://www.python.org/downloads/windows/) 安装，并选中 **Add Python to PATH**。
2. 双击本目录的 **Start-Workshop.cmd**。不需要先开 Unity，也不需要安装 Node。
3. 首次启动会建立本目录 `.venv` 并安装 Pillow、NumPy、SciPy 和 OpenCV headless，仅修改这个工具自己的运行环境。第一次准备依赖需要联网，失败时会显示原因；修复网络后重新双击即可。
4. 浏览器自动打开 `http://127.0.0.1:8765`。重复启动会打开已有工坊，不会再开一份服务。

后续只需要双击。服务在后台运行；关闭网页不会停止服务，页面左下的“退出服务”会保存后关闭后台。项目在 `data/` 中，保留这个目录即可保留作品。

若要手动启动，在本目录终端运行：

```powershell
.venv\Scripts\python.exe server.py --open
```

自定义端口：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File start.ps1 -Port 8770
```

启动器只对这一次脚本执行使用 Bypass，不修改系统持久执行策略。运行失败可查看 `server-error.log`。端口被其他软件占用时不会杀掉那个软件，请改端口。

## 2. 不开 AI，先体验编辑与导出

1. 点击“新建”，输入项目名。
2. 为此练习选择 **96×128 / 48 PPU**，点击“导入图集”。
3. 选择 `examples/lantern-exercise.png`。这是程序绘制的编辑练习图，不是 AI 角色或视觉质量样板。
4. 动作名称填 `lantern_exercise`，**2 列、2 行、4 帧**；背景选“保留现有透明度”。取消“整段动作统一缩放”，保持原生像素。
5. 点击“导入并检查”。用时间轴切帧、空格播放，再用铅笔修一个像素，撤销、重做试试。
6. 顶部显示“已保存”后点击“导出素材”。下载 ZIP 中会有图集、切片 JSON、透明动画预览和可再次导入的项目。

也可以“＋空白动作”从零绘制。只有手动添加或复制的帧，不会被描述成 AI 已完成的角色动画。

## 3. 从立绘生成

1. 上传角色的**全身正面立绘**。尽量让头顶、手脚、武器和饰物完整。选风格、画布、PPU。三种风格是配方，需要逐个角色视觉核对。
2. 打开 **Gemini** 开关。它每次进入页面默认关闭；关闭后清空页面中的 Key。
3. 到 [Google AI Studio](https://aistudio.google.com/apikey) 管理自己的 Gemini API Key，在工坊密码框输入。Gemini 网页订阅与 API 可用额度不是同一凭据；以你账号实际可用模型、权限和账单为准。
4. 默认模型 ID 为 `gemini-nano-banana-2.1`，可以自行更换为账号可用的图像生成模型。模型下线、无权限、限流都会显示实际失败状态，不会用空白图代替成功。
5. 第一次建议先选“单个动作 / 待机 / 正面”，输入角色关键特征并生成。检查身份后，可以展开“返修与方向母版”，固定当前帧为正面母版。各方向分别固定自己的母版，避免镜像配饰。
6. 再选择“移动包”或“战斗包”生成。每个动作/方向独立请求、独立保存；已有动作自动跳过。第一次整包没有各方向母版时，侧面/背面仍是 AI 推断，需要复核。

默认动作：移动包是四向待机（各4帧、2 FPS）＋四向行走（各8帧、10 FPS）；战斗包是向右战斗待机、普攻、施法、受击、倒地。攻击等动作默认单次播放。

**联网与费用**：Key 只在当前页面和正在执行的请求内存中存在，不写文件、localStorage、sessionStorage、日志或导出包。图片和提示词会发送到 Google。一次动作对应一次 API 请求；当前不会自动重复收费请求。请先用单个动作评估耗时与费用，整包最多发出 8 次（移动）或 5 次（战斗）请求。

“停止后续生成”无法撤销已经发出的请求；它返回后仍保存结果，再停止。超时也可能已经计费。重启后重新打开项目、填 Key、再点生成即可补缺失动作。页内任务 ID 可恢复，但 Key 不会恢复。

## 4. 如何返修

- **改像素**：暂停到问题帧，用图层编辑器修改。下方时间轴和 WebGL 预览立即更新。
- **重做一个动作**：选择“单个动作”和方向，勾选“替换选中的单个动作”，描述具体问题后生成。原始 AI 图稿留在 `data/项目ID/sources/`，可在右侧下载；当前动作替换后重新待验收。
- **AI 网格画歪**：工坊拒绝不能整除的网格。下载真实源稿，先裁掉边距或在图像编辑软件修正格线，再导入；不要逐帧拉伸塞满。当前版本尚无任意切线编辑器。
- **一处局部不对**：优先手工修该帧。当前自动返修单位是整个动作；“具体问题”是生图要求，不保证模型只改该像素区域。

自动处理对整个动作使用共同包围框、一次统一比例和同一偏移，不逐帧居中。色板共享范围为当前动作；跨动作风格由方向母版和视觉复核控制。固定描边锁颜色，不代表消除了轮廓抖动。

## 5. 像素编辑器怎么用

- **B 铅笔 / E 橡皮 / G 填充 / I 吸色**：在原生格上操作，笔刷支持 1～8 像素。
- **L 直线 / R 矩形 / O 椭圆**：拖出硬边像素形状。
- **M 选区 / V 移动**：框选后可以 Ctrl+C、Ctrl+V、Delete；用移动工具拖动选区。没有选区时移动整个当前图层。Escape 取消选区。选区当前用于复制/移动/删除，不作为绘画蒙版。
- **图层**：每帧最多8层，支持添加、命名、显示隐藏和上下排序。仅编辑当前帧，其他帧不会跟着改。当前没有图层透明度、混合模式或 PSD 导入。
- **时间轴**：空格播放暂停，左右方向键切帧；新增空白帧、复制帧、调序与删除。复制是编辑操作，重复帧会在检查中提醒。
- **洋葱皮**：暂停时叠加前一帧，帮助对齐。导出不会带入洋葱皮和辅助网格。
- **画布**：整数倍缩放；滚轮上下平移，Shift+滚轮左右平移。更改缩放会回到画布中心。
- **Ctrl+Z / Ctrl+Y**：撤销、重做，保留最近24次编辑状态。Ctrl+S 保存；平时停止编辑约1秒后自动保存。历史不跨浏览器重启。

这是针对角色图集的轻量像素编辑器，并非完整 Photoshop 替代。每个项目最多32个动作、每动作32帧，每帧8层，最大画布256×256；为了控制内存与网络传输，单项目图层像素总数有限制。复杂大角色请拆成多个项目。

## 6. 风格、尺寸与 PPU

画布控制真正的像素格，PPU 控制游戏里的世界大小。96×128 / 48PPU 的画布占 2×2.67 世界单位，但人物只占其中不透明部分。将 PPU 调成96会改变世界尺寸，不会提高像素清晰度。

已有动作后画布尺寸锁定，防止无提示重采样。需要另一尺寸时新建项目再导入转换。PPU、颜色数和描边可继续调整；颜色与描边配置只作用于下一次处理，不会偷偷重画已编辑帧。

## 7. 验收、导出与 Unity

检查会报告空帧、半透明边缘、全部重复帧、触边与色数；身份、五官、手腕、服装侧别、换脚和动作逻辑仍由人逐帧确认。只有修复技术阻断后，才能选择“我已逐帧验收通过”。改图会让该动作回到待验收；只改FPS不会改变图集哈希。

ZIP 内容：

```text
manifest.json               整包规格、动作及验收状态
project.pixel.json          完整可编辑项目，可在导入面板重新打开为副本
walk_e/atlas.png            透明 PNG 图集
walk_e/atlas.json           左上原点切片、FPS、PPU、基点、哈希、来源与检查
walk_e/preview.apng         保留真实颜色与透明度的动画预览
Unity/Editor/PixelWorkshopImporter.cs
IMPORT.txt
```

目前导出全部动作，包括候选；使用 `manifest.json` 区分状态，不把整包下载成功当作全套已验收。APNG 可用现代浏览器打开；不是GIF，不受256色调色板限制。原始AI源稿另存项目目录，不随素材ZIP导出，完整备份请连同 `data/` 一起保存。

Unity 2022.3：将导入脚本放到 `Assets/Editor/`，将某动作的 `atlas.png` 和 `atlas.json` 一起放入 Assets。选中PNG，菜单 **Assets → 像素工坊 → 按相邻 JSON 切片**。脚本设定 Point、无压缩、无Mipmap、指定PPU、底部中央基点，并将左上坐标转成Unity左下坐标。它不会创建Animator或完整角色控制器。脚本本轮未在Unity中编译验证，不应当成已完成引擎接入。

## 8. 常见问题

- **开关关着为什么不生成？** 关闭AI表示没有自动绘制后端。此时可以导入、手绘或复制生成要求到Gem。
- **正面很像，背面不像？** 正面没有背面信息。先补全并认可各方向母版；单张输入不能保证隐藏结构准确。
- **为什么有待验收？** 这是实际状态，不是软件故障。像素处理通过不能说明AI把手画对了。
- **修改后保存失败？** 检查尺寸和文件空间；多窗口同时修改会被版本检查拦截，防止后保存覆盖先保存。先保留当前页面，再另开窗口核对最新项目。
- **浏览器不支持 WebGL？** 工坊显示“Canvas兼容模式”；编辑与导出仍可用。建议更新 Edge/Chrome 并启用正常图形加速。
- **怎么备份？** 导出ZIP保留可编辑副本，或退出服务后复制整个 `data/`。不要只备份 `.venv`。

## HD2D 像素法线与项目管理

在左侧「制作规格」勾选 **HD2D · 像素法线**，用「轮廓起伏」调整强度。画布上方可切换 HD2D 光照 / 原始色稿 / 像素法线，拖动光源方向查看受光。不开 Gemini 也能对导入的图集生成法线；开启 Gemini 时，生成要求同时增加像素体积、衣褶与中性色稿约束。已有颜色图不会因勾选而自动重画。洋葱皮仅在原始色稿视图显示，绘画始终修改颜色图层。

导出 ZIP 每个动作新增 `atlas_normal.png`，与 `atlas.png` 同网格、同尺寸、同透明度；`atlas.json` 记录法线约定。法线是线性切线空间数据（+X 右、+Y 上、+Z 朝观察者），使用 Point 采样；接入引擎时使用支持法线的材质。现有 Unity 切片脚本仍只处理颜色图，材质绑定需手动完成。自动法线通过轮廓推算起伏，不是从一张立绘恢复真实三维人体、面部或衣褶；请逐帧验收。预览光照不烘焙进原始颜色图或 APNG。

点击角色项目卡片，可按名称搜索，查看缩略图、动作数和 PPU。每项右侧「删除」移入回收站；切换「回收站」后点击「恢复」即可找回，图层与 AI 原稿保留。生成任务运行时不能删除该项目；多个窗口同时修改时会提示版本冲突，避免旧页面覆盖已删除项目。回收站不会释放磁盘空间。

## Pixel Art Fixer：网格修复与八方旅人方向

首次启动会在工坊自己的虚拟环境中安装 NumPy、SciPy 和无界面 OpenCV；之后修复完全离线，不上传图片、不消耗 Gemini 额度。在线容器也包含同一修复引擎，处理发生在部署服务器。

1. 选择「八方旅人方向 · 立体像素」，自动开启「HD2D · 像素法线」和「Pixel Art Fixer · 生成后修复」。可分别取消。该风格要求原生像素台阶、材质 3～5 阶明暗、冷色暗部、衣褶和叠穿遮挡，整段保持色阶与体积特征；它影响下一次生成，不会自动把旧画改成该风格。
2. 导入已有伪像素图：在导入窗口勾选「Pixel Art Fixer · 恢复真实像素网格」，正确填写动作行列和有效帧数。开启后不再执行普通缩放、限色或描边处理，保留恢复后的可见像素。
3. 修复已经导入的动作：点击画布顶部「修复像素」。默认按编辑画布原生步长 1 修复；若明确有放大网格，可在弹窗改为自动检测或 2/3/4/6/8 px 校准。工具保留原动作及图层，新建 `_fixed_…` 修复副本；副本是合成后的单图层候选。已是原生像素的素材通常无需重复修复。
4. 修复完成后查看前后对照、原生恢复图的 4 倍最近邻预览、检测步长及置信度；可下载原生 PNG 与 JSON 检测报告。质量面板可以再次打开对照。自动与手动步长在报告中明确区分，手动不称为自动识别。自动检测可能把稀疏图形的尺寸当作像素步长；出错时用已知网格校准。自动检测出错时从「AI / 修复原稿」下载原图和恢复图检查，修正源稿的网格/留白再导入。
5. 导出时，HD2D 开启会在修复后的同一像素坐标上产生 `atlas_normal.png`；颜色/法线同网格、同透明度。法线使用轮廓起伏，不能恢复真正的脸部、衣褶三维结构，也不会补画错误动作。

整张动作图集只检测一次网格，所有帧共用同一个整数注册偏移，保留帧间位移。固定画布只补透明边距，不再缩放；若人物触及分格线或放不进画布，停止导入并保留原生图和报告。边长最少 16、整图最多 400 万像素，单次检测最长 180 秒。不要把低置信度或技术检查通过等同于美术验收；八方旅人方向的形体、手袖、五官和帧间体积必须视觉确认。

第三方代码为 Retro Diffusion Pixel Art Fixer（MIT），固定版本和哈希见 `vendor/upstream.json`，许可证见 `vendor/PIXEL-FIXER-LICENSE`。没有调用上游已过期的 CLI。
