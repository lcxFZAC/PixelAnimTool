A SMALL GUIDE

第一次来到像素工坊

  1. 先建立你的角色

    点击“新建”，上传全身正面立绘。选择风格、画布与 PPU。已有动画后，画布尺寸锁定；需要不同尺寸请新建项目。

  2. 选择一个起点

    不开 AI：导入图集或从空白开始画。开 AI：输入自己的 Key，选动作包，点击生成。源图会联网发送，费用由你的 API 账号承担。

  3. 看动画，也看每一帧

    空格播放暂停，方向键切帧。铅笔 B、橡皮 E、填充 G、吸色 I、直线 L、矩形 R、椭圆 O、选区 M、移动 V；Ctrl+Z 撤销，Ctrl+Y 重做。选区支持 Ctrl+C/V、Delete，拖动移动工具可挪动当前图层或选区。滚轮上下平移，Shift+滚轮左右平移画布。

  4. 固定母版，再扩展动作

    检查角色身份与方向，固定当前帧为该方向母版。后续生成同时参考立绘与母版。母版只是约束，不保证 AI 不会出错。

  5. 导出带规格的素材

    编辑自动保存，关闭页面前确认“已保存”。导出 ZIP 包含 PNG、JSON、透明 APNG 动画、可编辑项目和 Unity 导入脚本。视觉认可只作用于当前图集哈希。

Gemini 请求可能需要数分钟。停止按钮会停止后续请求，无法撤销已经发出的请求。服务重启后点击生成可跳过已有动作继续制作。API Key 不会写入项目、浏览器存储或导出文件。
