# 工作流沉淀

## 整段动作使用同一坐标变换

切图后计算整段共同包围框、统一比例和统一偏移。不要对每帧单独自动居中，否则会吞掉原始位移并引入步态抖动。回归检查用两帧不同位置的图形验证相对位移仍保留。

## 验收绑定合成像素

验收哈希来自实际可见图层的逐帧合成像素；改图、换图或改变可见层后重新待验收。帧率属于播放元数据，单独调速保留相同图集哈希。技术检查与用户视觉认可分开，不把PNG成功导出当作动画质量通过。

## 本地与在线共用引擎，不复制处理规则

在线容器从仓库根目录打包本地工坊的引擎与界面。Gem只维护输入约束与动作路由，不谎称能执行未接入的工具。修改动作默认值时同步检查 `presets.json`、Gem标准和指南。

## Windows 启动器的解释器检查

PowerShell 调用原生程序的引号转发可能改变 `python -c` 中的嵌套字符串。依赖版本检查放进独立Python文件，避免把带引号的Python表达式经PowerShell再解析。本次启动器实测暴露并修复了这一问题。

## 密钥与任务分离

API Key不进入项目或持久化任务。任务只记录项目ID、状态、已完成数量与错误；任务取消只阻止后续请求，不能声称撤销了已发出的云调用。回归检查覆盖取消时保留已返回素材、停止后续调用，以及文件中不存在测试Key。

## HD2D 法线与删除恢复（2026-10-08）

轮廓法线的预览与导出必须采用同一版本算法，跨 JavaScript/Python 用逐字节对照验证。法线是线性向量数据，不应用颜色图的限色、描边或 sRGB 解码；保持逐帧网格和 alpha 一致。法线功能或起伏参数变化应重置视觉验收，预览光源方向不改变资产。轮廓起伏只能标为候选，不等同于真实三维形体恢复。

项目删除采用带版本检查的软删除；读取、保存、AI 原稿下载均拒绝已删除项目，生成中拒绝删除。恢复沿用原 ID 并保留素材；旧窗口保存不可复活已删除项目。验证覆盖原图层/源文件保留、版本冲突和恢复路径。
